Sicherung

Die Protokolle liegen nur in diesem Browser auf diesem Gerät. Werden die Browserdaten gelöscht, sind sie weg. Deshalb regelmäßig eine verschlüsselte Sicherung speichern, z. B. auf einem USB-Stick. Sie lässt sich nur mit der Passphrase öffnen.

Spracherkennung

Läuft vollständig auf diesem Gerät. Beim ersten Diktat wird das Sprachmodell einmalig geladen (Programmdateien, keine Protokolldaten), danach funktioniert es auch offline.
